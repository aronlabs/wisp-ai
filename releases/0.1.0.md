# More reliable conversations, updates at your pace

## New

- Choose **Stable** for regular releases or **Nightly** for the latest changes in **Settings → App updates**.
- Browse release history on the web, with a permanent link and download for each version.
- GPT-6.1 Sol is now the default model for new conversations.

## Improved

- Chats, routines, memory and panels are stored together for more reliable persistence.
- Read formatted release notes in the app before updating.
- Wisp detects WoW Forever installations through Battle.net.
- Run **/wisp diag** to compare the loaded addon and desktop versions after updating.
- Update progress is clearer, and notifications dismiss automatically.

## Fixed

- Replies preserve their original content and display Markdown tables natively in the addon.
- Item and spell references remain available on hover in mixed replies.
- Unicode symbols use font-safe fallbacks in the addon.
- Wisp connects correctly when WoW omits default addon states.

After updating, use **Install / update addon** and reload WoW to load the matching addon.
