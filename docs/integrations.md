# Integration capability audit

The original integration work grouped existing tools; it did not implement all proposed addon adapters. This audit is the implemented scope, rather than a list of promised tools.

| Provider                    | Agent tools                                                                                                       | Why these belong here                                                                                                                                                                                         |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Questie / QuestieDB Forever | `questie__find_npc_locations`, `questie__find_object_locations`, `questie__get_quest`, `questie__get_quest_chain` | Verified static spawn locations, objective entity IDs, quest requirements and bounded prerequisite/follow-up graphs. Does not replace live quest progression.                                                 |
| Syndicator                  | `syndicator__find_item`                                                                                           | Item observations across visible same-realm/faction characters, bags, bank, mail, equipped and auction storage. Guild results are opt-in. Baganator already uses this inventory provider.                     |
| Auctionator                 | `auctionator__get_item_prices`                                                                                    | Batch reads of last-seen unit prices with coarse scan age. No scanning, purchase, posting or fabricated price history.                                                                                        |
| TheWoWDB                    | `thewowdb__search_database`, `thewowdb__get_database_entity`                                                      | Search and typed entity retrieval already cover catalog entities without one nearly identical tool per entity type. Forever is enforced.                                                                      |
| Wowhead                     | `wowhead__web_search`                                                                                             | Forever-scoped fallback search.                                                                                                                                                                               |
| Web pages                   | `web_fetch`                                                                                                       | Read known public HTTPS URLs using Impit with Chrome TLS impersonation and navigation headers, independently of the search provider. Markdown by default; text/HTML optional. No browser, account or API key. |
| WoWSims Forever             | `wowsims__simulate_dps`                                                                                           | Already accepts multiple explicit rotation plans for comparison; separate “compare” or “best rotation” wrappers add no capability. Supported character adapters remain explicit.                              |
| Everloot                    | The existing whitelisted MCP tools                                                                                | Complementary vendor/drop/quest relations, talents, professions and market history. Do not duplicate these as local aliases.                                                                                  |

Current game readings/actions remain core capabilities. Panels and suggestions remain separate product features. No integration edits another addon's source code.

Web fetch uses Impit with the Chrome profile and full document-navigation headers (verified against the Mobalytics mage leveling guide). A short-lived authenticated loopback CONNECT tunnel validates every destination's DNS answers and connects to a validated public IP, preserving origin TLS/SNI without allowing DNS rebinding. Redirects are handled manually and revalidated; credentials and private/reserved destinations are rejected. Downloads are limited to 5 MB; each output contains up to 50 KB / 2000 lines. A truncated response includes nextCursor; pass it as cursor with the same URL to continue the same converted snapshot without another network request. Fragments preserve all characters, including long lines and Unicode, and include startOffset/endOffset/totalCharacters. Cursors are conversation-scoped, retain their format, and expire after 10 minutes or an engine restart. The process-local cache is bounded to 32 snapshots and 32 MB; expired or evicted cursors return an explicit restart error. Timeout defaults to 30 seconds (maximum 120); cancellation closes the tunnel and connections. HTML is converted locally with scripts removed; relative links are resolved against the final URL. It does not execute JavaScript, solve captchas or bypass authentication, and challenge responses are returned as HTTP failures without retry loops. Page text is untrusted reference data, and game facts still require Forever version verification. The Web pages integration and its child tool can be disabled in capability settings.

Readiness is per API, not just per addon. Questie's quest and object tools stay unavailable when only its NPC API is present. Syndicator must finish initializing. Auctionator can expose price reads with unknown ages when its age API is absent. Reports expire on disconnect; master switches preserve individual choices. The agent receives both disabled and unavailable tool names in `integrations_context`.

Questie results distinguish static relationships, missing fields and fresh completion flags. Chains are bounded by depth, node count and field budgets; missing records and omitted branches are explicit. Object coordinates use the same native-map and Forever frame validation as NPC coordinates. Inventory and auction caches never prove that an item is absent, currently accessible or available to buy.

Not implemented: a complete Questie leveling route engine or arbitrary zone-wide availability scan; autonomous auction scans/trades; fake historical prices from Auctionator's latest-price cache; integrations for Details, RXP or TomTom without an installed/verified provider. Add these only for concrete use cases with their own API adapter and tests.
